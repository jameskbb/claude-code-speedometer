# Support

Speedometer is supported through GitHub, in this repository.

- **Bugs and questions**: open an issue at
  <https://github.com/jameskbb/claude-code-speedometer/issues>. The bug
  report form asks for the plugin version, your Claude Code version, your
  terminal and the gauge cluster you use.
- **Feature requests and new cluster ideas**: open an issue with the feature
  request form.
- **Security problems**: do not open a public issue. Report them privately as
  [SECURITY.md](SECURITY.md) describes.
- **Privacy**: what the plugin reads, keeps and sends is in
  [PRIVACY.md](PRIVACY.md).

The maintainer, GitHub user jameskbb, reads new issues and aims to reply
within a week. Fixes ship as a new plugin version; `/plugin update
speedometer` picks it up.
